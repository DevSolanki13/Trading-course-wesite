# Billing document fonts

Noto Sans Regular and Noto Sans Devanagari Regular are bundled for offline PDF rendering of Latin and Hindi text. They are not public course media.

Sources:

- [Noto Sans Regular](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf)
- [Noto Sans Devanagari Regular](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSansDevanagari/NotoSansDevanagari-Regular.ttf)
- [License](./OFL.txt)

The originals are unmodified. PDF subsets are embedded at generation time. Unsupported scripts/emoji use a visible question-mark glyph in the PDF; the separately downloadable escaped UTF-8 HTML document preserves the exact original text. All documents remain private and are marked as sandbox records.
